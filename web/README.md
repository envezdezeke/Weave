# Event Baskets web app

Next.js 16 frontend for Event Baskets.
It currently runs on mock data; see [`../docs/frontend/PROTOTYPE.md`](../docs/frontend/PROTOTYPE.md) for what is real and what is mocked, and [`../docs/frontend/CHANGE_PLAN.md`](../docs/frontend/CHANGE_PLAN.md) for the planned changes.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Read `AGENTS.md` before changing routing or data fetching: Next 16 differs from older versions.
